LGU Admissions Chatbot

Demo page — the widget loads bottom-right, exactly as it would on lgu.edu.pk.

This page is a stand-in for the real admission site. The chatbot itself is the green bubble in the corner.

Try asking

  • BSCS ki fee kitni hai?
  • MS Computer Science ka admission criteria kya hai?
  • How do I apply for admission?
  • Scholarships kaunse available hain?
  • BS Software Engineering ka roadmap dikhao
  • PhD ke liye kitne marks chahiye?

Embedding on the real site

One tag, anywhere before </body>:

<script src="https://YOUR-BACKEND/widget.js"
        data-api="https://YOUR-BACKEND"></script>

Ships with the LGU green + gold theme by default. Optional overrides: data-accent (primary green), data-gold (accent), data-title.
